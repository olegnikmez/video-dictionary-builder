# Генератор Видео-словаря (FFmpeg & Edge-TTS)

Десктопное приложение для автоматической генерации видео-словарей и обучающих материалов по иностранным языкам. Утилита принимает на вход текстовый файл с парами фраз, синтезирует естественную речь с помощью нейросетевых голосов Microsoft Edge TTS и собирает итоговый видеоролик через FFmpeg без использования платных API.

## Основные возможности

* **Графический интерфейс (PyQt6):** Интуитивное управление всеми параметрами рендеринга без необходимости править код. Состояние интерфейса автоматически кэшируется в `settings.json`.
* **Нейросетевой TTS:** Использование `edge-tts` обеспечивает высокое качество синтеза речи. Поддержка выбора дикторов и тонкой настройки скорости речи (0.5x - 2.0x).
* **Сложная типографика (Pillow):** 
  * Двухпроходный рендер шрифтов для устранения артефактов наложения при использовании большой толщины контура.
  * Независимая настройка шрифтов, размеров, межбуквенного интервала (tracking).
  * Настройка цвета, обводки, а также генерация полупрозрачных теней с настраиваемым смещением и размытием по Гауссу (эффект ореола).
* **Умное позиционирование:** Независимое выравнивание текста для каждого языка по вертикали (Сверху, По центру, Снизу) с динамическим расчетом высоты многострочных блоков.
* **Гибкий таймлайн:** Настройка количества повторений для каждой фразы, внутренних микро-пауз между повторами, порядка следования языков и главной паузы между переводами.

## Требования к системе

1. **Python 3.9+**
2. **FFmpeg:** Должен быть установлен в системе и добавлен в переменную окружения `PATH`. Утилита использует фильтры `aresample`, `anullsrc`, `concat` и H.264 энкодер.

Формат входного файла (TXT)
Файл должен содержать текстовые пары в строгом формате (каждая фраза в квадратных скобках, разделитель — точка с запятой ;). Кодировка файла — UTF-8 (или UTF-8-BOM).

Пример:

```Plaintext
[Und dazu noch einen Salat.] ; [А ещё салат.]
[Mach du mir bitte einen Tee.] ; [А ты сделай мне чай.]
[In zwei Tassen.] ; [В двух чашках.]
```
Архитектура
Слой UI (MainWindow): Отвечает за реактивность интерфейса, диалоговые окна и сериализацию стейта.

Worker-слой (BuilderThread): Выполняет тяжелые I/O-операции в отдельном потоке (QThread), предотвращая блокировку Event Loop'а графического интерфейса.
